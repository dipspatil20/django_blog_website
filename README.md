# 📝 Django Blogging System – Role-Based CMS

A production-ready blogging platform built using Django with authentication, role-based access control, dashboards, search, and comment management.


🚀 Live Demo

🔗 Live URL: https://dipaleepatil.pythonanywhere.com/

🔗 GitHub Repository: https://github.com/dipspatil20/django_blog_website.git

---

## 🚀 Features

### 👤 User Features
- User Registration & Login
- View blog posts by category
- Search blogs with pagination
- Comment system (authenticated users only)
- Featured & recent posts display

### 🛠️ Role-Based Access (RBAC)
- Multi-role system (Admin, Manager, Editor, Author)
- Django Groups & Permissions integration
- Granular access control using decorators

### 📊 Dashboard Features
- Role-specific dashboards
- Manage blog posts (Create, Update, Delete)
- Category management
- User management (Admin level)

---

## 🧰 Tech Stack

Backend: Python, Django  
Database: SQLite  
Frontend: HTML, CSS, Bootstrap  
Authentication: Django Authentication System  
Authorization: Django Groups & Permissions  
Deployment: PythonAnywhere

## ⚙️ Installation & Setup

1. Clone the repository

git clone https://github.com/your-username/django-blog-cms.git  
cd django-blog-cms  

2. Create virtual environment

python -m venv venv  
venv\Scripts\activate   (Windows)

3. Install dependencies

pip install -r requirements.txt  

4. Apply migrations

python manage.py migrate  

5. Run server

python manage.py runserver  

Visit:  
http://127.0.0.1:8000/
